Задание №1. Анализ блочной модели

Пример элемента
Параметр content-box border-box
Ширина содержимого 360 px 291 px
Высота содержимого 180 px 113 px
Полная ширина блока с рамкой и padding 429 px 360 px
Полная ширина вместе с margin 519 px 450 px
Полная высота блока с рамкой и padding 247 px 180 px
Полная высота вместе с margin 297 px 230 px

При content-box width и height задают только область содержимого. Поэтому к ним добавляются padding и рамка.

При border-box width и height включают содержимое, padding и рамку. Поэтому размер содержимого уменьшается.

Задание №4. Ограничения размеров и overflow

Первый абзац: блочная модель описывает размер элемента и его отступы.

Второй абзац: width задаёт основную ширину, а padding увеличивает общую ширину при content-box.

Третий абзац: border-box изменяет способ расчёта ширины и высоты элемента.

Четвёртый абзац: overflow: auto автоматически добавляет полосы прокрутки, если контент не помещается.

Пятый абзац: hidden скрывает лишнее содержимое, а scroll всегда показывает полосы прокрутки.

Дополнительный текст помогает увидеть работу каждого режима прокрутки.

Режим hidden

Первый абзац для проверки hidden.

Второй абзац не помещается целиком в заданную высоту.

Третий абзац скрывается вместе с остальным лишним содержимым.

Четвёртый абзац показывает действие свойства hidden.

Пятый абзац недоступен для просмотра прокруткой.

Режим scroll

Первый абзац для проверки scroll.

Второй абзац остаётся доступным через прокрутку.

Третий абзац находится ниже видимой области.

Четвёртый абзац показывает постоянные полосы прокрутки.

Пятый абзац можно прочитать, прокручивая блок.

auto показывает полосы только при необходимости, hidden скрывает лишнее, scroll всегда показывает полосы прокрутки.
